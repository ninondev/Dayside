## 1. README 安装段落替换

只有正式签名、公证后的 DMG 上传到 Releases 之后才替换，否则 README 会说假话。

`README.md` 里这一段：

> The app is signed ad hoc and is not notarized, so macOS blocks it the first time you open it.
> To open it, go to System Settings › Privacy & Security, scroll to the bottom, click
> "Open Anyway" and confirm with your password.

换成：

> The app is signed with a Developer ID and notarized by Apple, so it opens like any other app.
> The first time, macOS asks whether you want to open an app downloaded from the internet. Click Open.

`README.zh-Hans.md` 里这一段：

> 这一版是 ad-hoc 签名，没有经过苹果公证，所以第一次打开会被系统拦下来。到「系统设置 › 隐私与安全性」，拉到最下面，点「仍要打开」，再输入密码确认，就能打开了。

换成：

> 安装包用 Developer ID 签名，并经过苹果公证，可以像别的 App 一样直接打开。第一次打开时，系统会问你是否要打开从互联网下载的 App，点「打开」就行。

README 已知问题第 4 条（内存）按第 6 步的实测结果改；没有实测改善就不动。
