Overview

Dayside has no app accounts, advertising, or analytics. Its clock, city-search, time-conversion, meeting, timer, travel, and astronomy calculations run locally. The app does not send your calendars, contacts, plans, or preferences to the developer. You choose whether to use optional system permissions and whether to share any information.

Information stored on your Mac

The app saves your chosen places, custom names, display settings, people clocks, working hours, meeting preferences, timer state, daylight saving reminder settings, and travel plans, including the sleep times you enter. It also saves a configured sharing-page address and. These use local macOS app containers. Recovery backups may keep earlier or damaged preference data. The app also keeps a short local log of technical events, such as launches and menu bar state, for its diagnostics report; the log holds no place names, people, or calendar content.

Exporting a diagnostics report is an explicit action in Settings, Help. The report is a plain-text file that you save where you choose. It contains the app's technical state, your saved locations with their time zones, the time zones of your people clocks without their names, your settings, and that log, with home directory paths, email addresses, and link details removed; it never contains calendar events, contacts, or names, and it is not uploaded.

You can remove entries in the relevant tools. Deleting the app does not guarantee removal of its containers, preference backups, or files you exported. Copies you shared with other people are outside the app's control.

Calendars and meeting links

The agenda is optional. If you enable it and grant calendar access, Dayside reads events from your selected calendars. It uses calendar names, event titles, start and end times, event status and participation, and locations to display relevant events. It checks event URLs, locations, and notes for supported meeting links. The full query snapshot is held in memory. A small local widget snapshot can include meeting titles and start and end times, so these details may appear outside the main app window.

Adding a planned meeting to a calendar is a separate action; so is adding a rotation series or the clock-change events from DST Alerts, which contain place names and local times. It can request write-only calendar access or create a temporary ICS file for your calendar app to open. Calendar accounts may sync events according to their own settings. Opening a meeting link launches the external meeting app or browser; that service's privacy policy then applies. You can turn off the agenda or revoke access in macOS settings.

Contact import

Importing contacts is optional and initiated by you. The app reads contact identifiers and display names, using an organization name when needed. It saves the people you select and the locations, working hours, and vacations you enter. It does not read phone numbers, email addresses, or postal addresses to determine time zones. Import candidates are held in memory and cleared when the import flow ends.

Time text and local integrations

The system text service reads selected text only when invoked. The local deterministic engine reads time expressions and shows candidates for ambiguous input.

Shortcuts actions run inside the app and use its local data; nothing is shared with other processes. Copy actions write the chosen details to the macOS clipboard.

Notifications

Timer and daylight saving alerts use local notifications after you enable them and grant permission. macOS holds the scheduled requests, which can contain timer labels or place names. Dayside does not operate a push-notification server. You can disable alerts in the relevant tool or in macOS settings. Focus, sleep, and notification settings may affect when an alert is shown.

Sharing your availability

Sharing is an explicit action. The previewed snapshot may include a display name, time zone, working hours, available time windows, and a creation and expiry time. It does not read or publish agenda events. You can copy text, save a local HTML file, or create a link for an HTTPS page address you configure. Dayside does not automatically upload or publish the page. A time card, shown as a QR code or copied as text, contains the same snapshot plus the version of the time zone data on your Mac; when a hosting address is configured, the QR code contains the link instead. It is exchanged directly between people and is not sent through a server.

Link data is encoded in the part after #. This encoding is not encryption: anyone with the complete link or file can read the snapshot. A URL fragment is not part of the normal HTTP request, but page scripts and recipients can access it. The bundled sharing page has no analytics or outbound data requests. A host you use may still receive page-request information, such as an IP address, under its own policy. The published host has not been chosen for this draft.

Offline use

All features are free under GPL-3.0-only and work locally. Dayside has no network entitlement. Calendar synchronization, external links and pages you open use their own settings and policies.

Permissions and third parties

Dayside runs in the macOS App Sandbox. It does not request location, camera, or microphone access. Launch at login is optional. No analytics or advertising SDKs are included. Open-source license notices ship in ThirdPartyNotices.txt; city data is derived from GeoNames under CC BY 4.0.

Dayside 隐私政策

支持English

概况

Dayside 无需 app 账号，不含广告或统计分析。时钟、城市搜索、时间换算、会议、计时器、旅行与天文计算都在本机完成。app 不向开发者发送你的日历、联系人、计划或偏好。是否启用系统权限、是否分享内容，由你决定。

在 Mac 上保存的信息

app 保存所选地点、自定义名称、显示设置、人物时钟、工作时间、会议偏好、计时状态、夏令时提醒设置，以及包括所填睡眠时间在内的旅行计划。配置的分享网页地址也会保存。这些数据存放在 macOS 本地应用容器里。恢复备份可能保留较早或损坏的偏好原文。app 还会为诊断包记一小段本地日志，只有启动、菜单栏状态这类技术事件，不含地点名、人物或日历内容。

导出诊断包是你在设置「帮助」页主动发起的操作。诊断包是纯文本文件，保存位置由你选择；内容是 app 的技术状态、已保存的地点及其时区、人物时钟的时区（不带人名）、你的设置和上述日志，写入前去掉家目录路径、邮箱地址和链接细节，从不包含日历事件、联系人或人名，也不会上传。

你可以在相应工具中移除条目。删除 app 不保证同时删除容器、偏好备份或已导出的文件。已经分享给别人的副本不受 app 控制。

日历与会议链接

日程视图为可选功能。主动开启并授权后，Dayside 读取你所选日历的事件，使用日历名称、事件标题、起止时间、事件与参与状态及地点来显示相关日程，并从事件网址、地点和备注中识别受支持的会议链接。完整查询快照保留在内存；本地小组件快照可能包含会议标题和起止时间，因此这些信息可能显示在主窗口之外。

把规划好的会议加入日历是独立操作，把例会轮换的系列或「夏令时提醒」页的时钟调整日程加入日历也一样，这些日程里有地点名和当地时间。它可能申请日历只写权限，或生成临时 ICS 文件交日历 app 打开。日历账号可按自身设置同步事件。打开会议链接会启动外部会议 app 或浏览器，随后适用该服务的隐私政策。你可以关闭日程视图，或在 macOS 设置中撤销授权。

通讯录导入

导入通讯录由你主动发起。app 读取联系人标识和显示名称，必要时使用组织名称，并保存你选入的人物及手动填写的地点、工作时间和休假。不读取电话、邮箱或邮寄地址来推断时区。导入候选列表保留在内存，导入流程结束后清除。

时间文本与本地集成

调用系统文本服务时，app 才读取所选文字。时间表达由本地确定性引擎读取，歧义给出候选。

快捷指令动作在 app 进程内运行、使用 app 自己的本地数据，不与其他进程共享。复制操作会把所选内容写入 macOS 剪贴板。

通知

计时器和夏令时提醒在你开启并授权后使用本地通知。macOS 保存待发送请求，其中可能包含计时器标签或地点名称。Dayside 不运行推送服务器。你可以在相应工具或 macOS 设置中关闭提醒。专注模式、睡眠和通知设置可能影响提醒显示的时间。

分享可约时间

分享由你主动发起。预览的快照可能包含显示名称、时区、工作时间、可约时段、生成时间和有效期；它不读取或发布日历事件。你可以复制文字、保存本地 HTML 文件，或为自行配置的 HTTPS 网页地址生成链接。Dayside 不会自动上传或发布页面。时间名片以二维码显示或以文本复制时，内容与快照相同，另加本机时区数据的版本；配置了托管地址时，二维码里是那个链接。名片在两个人之间直接交换，不经过服务器。

链接数据编码在 # 后面。这种编码不是加密，获得完整链接或文件的人都能读取快照。网址片段通常不包含在 HTTP 请求中，但网页脚本和收件人可以读取。随 app 附带的分享页没有统计分析或对外数据请求；你选用的主机仍可能根据其政策记录 IP 地址等页面访问信息。本草稿尚未选定发布主机。

购买及其他联网行为

全部功能永久免费，采用 GPL-3.0-only，在本地运行。Dayside 没有网络权限。日历同步、外部链接和你打开的网页按各自设置和政策使用网络。

权限与第三方

Dayside 运行在 macOS App 沙盒内，不申请位置、相机或麦克风权限。开机自启为可选项。不含统计分析或广告 SDK。开源许可说明随包保存在 ThirdPartyNotices.txt；城市数据来自 GeoNames，采用 CC BY 4.0 许可。
